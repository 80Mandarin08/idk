# Матрица ролей и прав

| Роль | Может | Не может / ограничения |
|---|---|---|
| `operator_a`, `operator_b` | Создавать заявки; читать собственные; редактировать собственные открытые заявки | Не видит чужие заявки; не назначает исполнителя; не удаляет |
| `technician_a` | Читать только назначенные заявки; переводить open → `in_progress` → `resolved` с обязательным непустым комментарием | Не видит неназначенные; удаление запрещено; завершение без комментария невозможно |
| `manager_a` | Читать все заявки; назначать исполнителя | Не может незаметно менять автора или историю действий |
| Неавторизованный пользователь | — | Не читает и не создаёт заявки |

Примечание: доступ ограничивается сервером; отсутствие кнопки само по себе не является проверкой полномочий.
